## 1. EXP-07 — Anchor × Capacity 2×2 析因（H-34）

### 1.1 设计

4ep / seed0 / ebase，2×2：z ∈ {16, 32} × anchor ∈ {old(default), k-means}。4 格全部实测。

| cell | z | params_M | flops_G | mAP50 | mAP50-95 | da_mIoU | lane_mIoU |
|---|---|---|---|---|---|---|---|
| z16_old | 16 | 0.2014 | 1.0796 | 0.3879 | 0.1471 | 0.8124 | 0.5730 |
| z16_km | 16 | 0.2014 | 1.0796 | 0.3917 | 0.1504 | 0.8268 | 0.5755 |
| z32_old | 32 | 0.2157 | 1.2238 | 0.4161 | 0.1640 | 0.8277 | 0.5775 |
| z32_km | 32 | 0.2157 | 1.2238 | 0.4035 | 0.1573 | 0.8211 | 0.5742 |

### 1.2 必须只读交互项（主效应会骗人）

```
Δcap(old) = z32_old − z16_old = +0.0282
Δcap(km)  = z32_km  − z16_km  = +0.0118
interaction = Δcap(km) − Δcap(old) = −0.0164        # mAP50
main_capacity   = +0.0200
main_assignment = −0.0044
```

**交互项 −0.0164 = 1.123× 噪声**（1× = 0.0146）。

> ⚠️ 注意不要把 `z32_km (0.4035) < z32_old (0.4161)` 直接读成"k-means 有害"：在 z16 上 k-means 是 **+0.0038**（更优）。单格差异是主效应与交互项的混合产物，这正是必须做析因的原因。

### 1.3 13 个指标面：方向一致，但量级不过线

| 面 | interaction | 面 | interaction |
|---|---|---|---|
| mAP50 | **−0.0164** | det_AP95_small | −0.0028 |
| mAP50-95 | −0.0100 | det_AP95_medium | −0.0140 |
| da_mIoU | −0.0210 | det_AP95_large | −0.0589 |
| lane_mIoU | −0.0058 | det_rec50_small | −0.0027 |
| det_AP50_small | −0.0073 | det_rec50_medium | −0.0055 |
| det_AP50_medium | −0.0197 | det_rec50_large | −0.0191 |
| det_AP50_large | **−0.0936** | | |

**13/13 全为负** —— 方向与 H-34（"分配质量越好，容量的边际价值越大" ⇒ 交互项应为正）**系统性相反**。

### 1.4 Gate 判定

| gate 条件 | 结果 |
|---|---|
| 方向一致 | ✅ 13/13 负（与 H-34 相反） |
| 超 noise floor ≥2× | ❌ headline 1.12× < 2× |
| 非单曲线偶然 | ⚠️ 全部面同向，但 13 个面来自同 4 次运行、指标高度相关，不能当作 13 次独立检验 |
| 无 implementation artifact | ✅ 无（同 config 家族，仅 z/anchors 两变量） |

**结论：gate 未过 → EXP-07 的 20ep confirmation 不启动，H-34 按预注册规则 REJECT。**

### 1.5 机制读数（sub-threshold，仅作假设，不得当结论）

容量效应高度集中在**大目标**：`dCap_old(AP50_large) = +0.1327`，而 k-means 下只剩 `+0.0391`（交互 −0.0936）。中/小目标容量效应接近 0（AP50_medium `dCap_old = −0.0074`）。

> 这不是"k-means 削弱了容量"，而是**更好的锚框已经吃掉了容量本可带来的那部分大目标收益** —— 即两者**部分可替代（substitutable）**。这与 H-34 预测的**互补**关系相反，且与 §2.4 的 EXP-08 结果互相印证。
> **但这只是机制解释，量级未过 2× 判据，不得写成"已证实负交互"。**

## 2. EXP-08 — 等预算资源分配

### 2.1 四臂（20ep, ebase, z16）

| 臂 | n_seeds | params_M | flops_G | det mAP50 | det mAP50-95 | lane_mIoU | da_mIoU |
|---|---|---|---|---|---|---|---|

| **A** uniform `enc×1.40` | 1 | 0.3339 | 1.6650 | 0.5339 | 0.2420 | 0.5879 | 0.8581 |

### 2.2 预算平价检验（±5% 规则）

| 比较 | ΔFLOPs | ΔParams | 判定 |
|---|---|---|---|
| B vs C | **0.00%** | **0.00%** | ✅ 严格平价（同预算、同架构，仅 anchors 不同） |
| A vs C | **+1.58%** | **+65.79%** | ⚠️ FLOPs 轴在带内；**Params 轴严重越界** |
| A vs ref | +54.2% | +65.8% | ❌ 双轴均不平价 |

### 2.3 B vs C —— 本轮唯一严格单变量对照（**核心正面结果**）

逐字段 `diff` 两个 config 的 `model:` 块后确认：`phase4b_l14f1_z16.yaml` 与 `phase6_combo_danc_l14f1.yaml` **唯一实质差异是新增的 `anchors:` 块**（其余差异仅为 YAML 行内/块状写法）。因此这是 **params 与 FLOPs 完全相同的 anchor-only 对照**：

| 指标 | C − B | σ（3-seed pooled） |
|---|---|---|
| **det mAP50** | **+0.13923** | **29.2×** |
| **det mAP50-95** | **+0.08820** | **29.3×** |
| lane_mIoU | −0.00297 | 1.59× |
| da_mIoU | +0.00020 | 0.17× |

**读法：** 换一套 k-means 锚框（纯训练期先验，推理零成本、零参数、零 FLOPs），det 提升 **+0.139 mAP50 / +0.088 mAP50-95**（≈29σ）；而 lane / DA 在噪声内**完全不动**（1.59σ / 0.17σ）—— 符合"锚框只作用于检测头"的预期，说明提升不是全局扰动带来的。

**这是 Phase 6B 可对外陈述的最强结论。**

### 2.4 A vs C —— 非对称臂在 FLOPs 轴上输了，但归因不清

- A 比 C：**det +0.03583**（用 C 的 3-seed sd 0.00598 → ≈6.0σ），det95 +0.0253。
- 关键结构事实：**A 沿用了旧锚框（config 中无 `anchors:` 键）**，且 lane 分支未改；**C 用的是 k-means 锚框 + l14f1**。
- 也就是说：**A 是在"监督更差"的前提下赢下 C 的**。这反向强化了 §2.3 的结论（锚框确实是检测的主杠杆之一），并且**排除了"A 的胜出来自监督"这一解释**。

**但必须诚实标注一个未解决的混淆：A 的 params 比 C 高 65.79%。** 在"FLOPs 为主预算轴"的预注册规则下 A vs C 是可比较的（ΔFLOPs 1.58% 在 ±5% 带内）；然而这也意味着**A 的胜出无法区分是"分配形状"（均匀扩宽）还是单纯"参数更多"**。

> 因此：**非对称分配"优于"uniform 的说法被证伪（FLOPs 轴）；但"uniform 优于非对称"也只是一半结论（params 混淆）**。EXP-08 的分配形状问题 **UNRESOLVED**。

### 2.5 Pareto 与 cost

| 臂 | utility_meanrel | ΔFLOPs (rel) | ΔParams (rel) | 被支配 |
|---|---|---|---|---|
| A_uniform | **+17.45%** | +54.2% | +65.8% | 否（FLOPs / Params 两轴均否） |
| C_asym | **+14.36%** | +51.8% | +0.25% | 否（两轴均否） |
| B_spatial | +1.42% | +51.8% | +0.25% | **是（两轴均被 C 支配）** |

> ⚠️ Pareto 标记 C"未被 A 支配"仅因 A 的 FLOPs 高 1.58% —— **而这 1.58% 落在预注册 ±5% 等价带内**。在等价类内部，**A 支配 C**（更大 utility、同等 FLOPs 预算）。不要把 Pareto 标记读成"C 与 A 并列最优"。
>
> 成本归一化：B/C 相对 ref 的 ΔParams 仅 +0.25%，其 `utility_per_dParams` 已在统计脚本中标记为 `NA`（除零式比值不可解释）。

## 3. 对架构研究线（H-32 / H-33 / H-35）的影响

1. **H-33（单模型非对称任务路径）在本预算档不成立。** 非对称 combo 在等 FLOPs 下输给均匀扩宽 0.036 mAP50。若要把非对称作为核心主张，必须先解决 params 混淆（即做**等参数**的 uniform 臂），否则主张站不住。
2. **H-34（容量×监督耦合）REJECT。** 方向反了，量级也不过线。不要把它写进论文。
3. **新的 Level-1 观察（喂给 H-35"容量是多维的"）：维度之间更可能是替代关系而非互补关系。** 两条独立证据：
   - EXP-07：交互项 13/13 为负；
   - EXP-08：A（uniform 容量、**旧锚框**）> C（非对称、**k-means 锚框**）。
   两者都指向同一件事：**不同维度的资源在争抢同一部分可改进空间**。这比"容量是标量"更进一层，且是本轮唯一可重复的机制性主张。
4. **检测的主导杠杆排序（本预算档，实测）：** 监督/先验（锚框，零成本）≥ 表示容量（+54% FLOPs）**≫** 分配形状（本轮未测出正效应）。

## 5. 诚实性声明（limitations，不得省略）

1. **EXP-07 是 4ep / seed0 screening，不是结论级证据。** 我们据此*拒绝*启动 20ep（这是 gate 的用途），**不等于**我们证明了"容量与监督负交互"。要证明后者需要 seeds 与更长训练。
2. **13/13 同向不等于 13 次独立检验。** 所有面来自同 4 次运行且指标高度相关，我**没有**计算也未主张 p = 2⁻¹² 之类的数值。1.12× 才是预注册判据下的读数。
3. **只有 mAP50 有预注册的噪声标尺（0.0146）。** 其余 12 个面（含 det_AP50_large 的 −0.0936）**没有**对应的预注册 1× 标尺，所以"大目标面 −0.0936"不能直接换算成 σ 倍数；把它当强证据是越界。
4. **A 臂 n=1（seed0）。** A vs C 的 6σ 读数是拿 C 的 3-seed sd 当分母做的近似，未计入 A 自身的 seed 方差；真实的显著性必然弱于 6σ。
5. **EXP-08 的 A vs C 存在双重混淆**：params（+65.8%）与监督（A 用旧锚框）。前者不利于归因"分配形状"，后者反向有利于"容量"解释。两者方向不同，故不能给出单向的干净归因 —— 这正是 §4.2 列为下一步的原因。
6. **B 臂是 Phase 4B 复用产物**（`reused-phase4b-l14f1-e20`），非本轮新训练；其 3-seed 与 C 的 3-seed 在同协议下产生，可比，但来源列已如实标注 `reused`。
7. **FPS 不作为判据**（项目约定）；表中未列 FPS 差异。
