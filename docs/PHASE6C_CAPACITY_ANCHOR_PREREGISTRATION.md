## 0. 这个实验要判什么

**H-36（新）**：锚框监督（assignment/supervision 质量）与表示容量之间是**替代（substitutable）**关系，
而不是**可加（additive）**关系 —— 即容量越大，同一份监督改进带来的增益越小。

这是 Phase 6B 两条独立证据（EXP-07 负交互、EXP-08 中 A-uniform 用旧锚框仍胜过 C-asym）
所指向的同一个机制主张，也是本轮唯一可重复的机制性主张（决策报告 §3.3）。
本实验是它的**判决性检验**。

## 2. 必须先记录的 tier 警告（本轮最重要的前置发现）

| 档位 | Δ_anchor（r2_z16，km − old） |
|---|---|
| **4ep** | 0.3917 − 0.3879 = **+0.0038**（< 1× 4ep 噪声 0.0146） |
| **20ep** | 0.4982/0.4960 − 0.3543 = **+0.1428** |

**两者差 38 倍。** 含义：

> **EXP-07 的 4ep 筛选是在"锚框杠杆本身接近失效"的档位做的。**
> 在那个档位上测"容量 × 监督交互"，等于在监督效应 ≈0 的点上测它的斜率 ——
> 因此 **H-34 的 REJECT 必须追加标注："@4ep tier，而该 tier 上监督主效应未显现"**，
> 不能表述为"容量与监督不耦合"的一般结论。

同一条证据也解释了为什么 EXP-07 的 13/13 指标面交互全负却量级不过线：
它们测的是一个尚未启动的杠杆。

另一条必须记录的反常：**旧锚框臂 20ep（0.3543）反而低于它自己 4ep（0.3879）**。
说明 20ep 下旧锚框的检测在退化，而 k-means 臂在继续上升 —— +0.1428 里含有
"锚框影响收敛/退化"的成分，**不等于纯粹的"表示改善"**。第 5 节判据按此限制收窄。

## 3. 判据（开跑前固定）

### 3.1 噪声标尺 σ_20 的**推导规则**（不是事后挑的）

σ_20 := 本仓库在本次运行之前**已有的 20ep 多 seed 臂**的 within-arm seed-sd 的合并（pooled）值。

现存 20ep 多 seed 臂（EXP-08）：

| 臂 | 3 个 seed 的 det mAP50 | sd |
|---|---|---|
| B（l14f1） | 0.3612 / 0.3553 / 0.3600 | 0.00312 |
| C（combo） | 0.5047 / 0.4931 / 0.4964 | 0.00598 |

⇒ **σ_20 = √((0.00312² + 0.00598²)/2) = 0.0048**　（2σ_20 = 0.0096）

（旁证：`danc_z16_e20` 的 2 个 seed 极差仅 0.0022，与 0.0048 同量级或更小 —— σ_20 = 0.0048 是**保守**取法。）

### 3.2 主量：交互项

```
interaction = Δ_anchor(高容量) − Δ_anchor(低容量)
            = [ mAP50(C4) − 0.5339 ] − [ +0.1428 ]
```

**只读交互项**（主效应会被容量本身的巨大增益掩盖；沿用 EXP-07 §1.2 的同一条纪律）。

### 3.3 四分支判定（magnitude 门槛与显著性门槛**同时**要求）

| 分支 | 条件 | 判定 |
|---|---|---|
| **SUBSTITUTION** | `interaction ≤ −2σ_20` **且** `Δ_anchor(高) ≤ 0.5 × 0.1428 = 0.0714` | **H-36 SUPPORTED @ screening** → 允许进入 3-seed 确认 |
| **DIMINISHING** | `interaction ≤ −2σ_20` **但** `Δ_anchor(高) ∈ (0.0714, 0.1428)` | **部分替代**：增益被压缩但未腰斩 → 记为"递减"，**不得**表述为"替代" |
| **ADDITIVE** | `|interaction| < 2σ_20` | 无信号 → 报告 UNRESOLVED，**不**烧 3-seed |
| **COMPLEMENTARY** | `interaction ≥ +2σ_20` | **H-36 REJECTED**（容量与监督可加/互补）→ 机制主张撤回 |

> 为什么要 magnitude 门槛：σ_20 很小（0.0048），单靠 2σ 会把
> "Δ 从 0.143 掉到 0.130"也判成"替代"（技术上 2.7σ）——那是把统计显著当成效应大小。
> 本项目的纪律是**两个门槛同时过**。

### 3.4 可 falsify 的预测（写在开跑前）

EXP-07 在 4ep 测到的负交互（−0.0164）预测 interaction < 0。
具体化：**预测 Δ_anchor(高) 显著小于 0.1428，且若"替代"成立应落在 ≤ 0.0714。**

## 5. 诚实性限制（必须随结论一并陈述）

1. **容量轴不干净**：C3/C4 用的是 A-uniform（params **+65.8%**、FLOPs +54%），
   与 C1/C2 不只是"容量大小"之别，还有"容量加在哪个维度"之别。本文的 interaction
   因此是**跨维度容量**的交互，不能表述为"参数量的交互"。
2. **20ep 旧锚框臂在退化**（0.3879@4ep → 0.3543@20ep）：Δ_anchor 含收敛/退化成分。
3. **跨 seed 比较**：低容量 Δ 在 P6C-STEP1 完成前用 s1/s2，与 C1(s0) 不同 seed；
   `exp9_r2z16_km`（s0）跑完后改用 3-seed 均值重算，**两个读数都要报**。
4. **n=1 的格**：C3 是 seed0 单次。3σ 级结论必须等 P6C-STEP2。
5. **Screening tier**：P6C-STEP1 与 EXP-07 同属 screening tier（n=1，单档），
   只用于**决定是否继续投入**，不用于对外结论。
6. **FPS 不作为判据**（项目约定）。
