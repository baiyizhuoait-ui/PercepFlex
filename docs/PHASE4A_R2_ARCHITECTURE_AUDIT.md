# Phase 4A · R2 Architecture Audit

Generated by `scripts/phase4a_audit.py`. Provenance is established by
**intervention**: each head is re-run with Z replaced by noise and, separately,
with the encoder features replaced by noise. A head that moves when Z moves and
stays still when the encoder features move is Z-only. That is a measurement, not
a claim about what the code says.

---

## 1. Information flow

```
R0   Encoder -> [F2,F3,F4] -> Detection
     Encoder -> Z -> DA
     Encoder -> Z -> Lane

R2   Encoder -> Z -> reconstruction pyramid -> Detection
     Encoder -> Z -> DA
     Encoder -> Z -> Lane
```

`Z` is produced by `CompactRepresentation`: 1x1 lateral convs on F2/F3/F4,
bilinear upsample, add, BN, ReLU. It lives at **1/8 resolution** with
`z_channels` channels.

**Result.** R0's detection head is a genuine bypass: it is inert when Z is
replaced by noise and moves when the encoder features are. R2 removes it - all
three heads are Z-only, so R2 is a strict shared bottleneck.

## 3. Structural caveat that is not a bypass but is a real cost

Z sits at 1/8. The detection head needs 1/8, 1/16 and 1/32. R2 builds the two
coarser scales by **downsampling Z**, and Z itself was built by **upsampling**
F3 and F4 to 1/8. The 1/32 detection scale therefore travels

```
F4 (1/32) -> 1x1 -> upsample to 1/8 -> add into Z -> downsample to 1/32
```

This round trip is not a bypass (the path is forced through Z) but it is a
plausible source of spatial information loss, and it makes R2's detection result
partly a statement about the reconstruction, not only about Z width. This is
hypothesis H7 and it is why the reconstruction probe exists.

## 5. Verdict

- R0 detection bypasses Z: **confirmed**

Proceed to the 4-epoch sanity run only if both are confirmed.
